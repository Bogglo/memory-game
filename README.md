# 🎮 Memory Game

An interactive emoji-based browser puzzle game built with **HTML, CSS, and JavaScript**. Match pairs, track your time and attempts, and play on desktop or mobile.

## 🔗 Live Demo

▶️ [Play the Game on GitHub Pages](https://mrgoofydev.github.io/memory-game)

## ✨ Features

- Emoji-based card matching
- Timer and attempt counter
- Sound effects
- Win animation and replay screen
- Responsive desktop and mobile layout
- Reset and Play Again controls

## 🛠️ Technologies

HTML, CSS, JavaScript
